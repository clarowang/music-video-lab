## 使用记录应该保留什么

每批一份记录：谁为哪个项目使用、工作流/工具版本、输入哈希、音频角色、实际图与参数、改变的原因、原片和交付文件、每次失败/重试及费用、机器等待与人工操作、最终反馈。不要只记平台SUCCESS。

任务费除以交付秒数，是技术交付秒价；除以真正被选用的秒数，才是采用秒价。失败与重试计入分子，采用尚未知则不计算后者。人工时间没量过写未知，不写成0；并发任务的计算时间之和也不是整批等待时间。

调用者可以试新提示和新组合，但不改别人正在用的默认。小变化留下配方版本；新用途有重复证据后成为平行工作流，注明父版本、改动、正例和负例。面对上游新方法，先问它解决哪一段、能否接入、同素材对照是否有收益。

## 内部研究与公开版本

完整研究会有私有素材、账户配置和未完成假设；公开仓库只包含明确选择的阶段成果。共用代码在本仓库维护，内部调用同一来源；配置、素材与披露节奏分别管理，不需要复制两套算法。

本次公开更新不增加媒体，不公布账号、完整角色库或新的歌曲素材。内部的记录工具与Windows队列未随本次公开；本仓库不负责收费提交，也没有跨账号无人值守验证。已有视频许可仍见[许可范围](../LICENSES.md)。
