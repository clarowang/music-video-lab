# H3：哪些镜头已经有希望，哪些还要继续试

记录日期：2026-09-10。本页重点公开T8配方这批19次RH任务，总计22个模型原片、659 RH币。此前另有一批24次任务、23原片、1535 RH币；两批账目独立。这里只发布精选媒体，不把9份展示片当成全部尝试。

## 唱歌：低成本候选成立，精准口型尚未宣告通过

冻结同一段9.2秒人声、人物图和原曲，比较轻量H3、换种子、提高原生尺寸、FlashVSR及同日已完成Wan基线。展示片接回原曲，不变速、不用同步测量结果移动音轨。

| 方案 | 任务实扣RH币 | RH报告任务秒数 | 规格 |
|---|---:|---:|---|
| D01 轻量H3 | 29 | 142 | 原生576×1024，24fps |
| D03 同配方第二种子 | 26 | 130 | 原生576×1024，24fps；未列入首版精选视频 |
| D05 提高原生尺寸 | 54 | 266 | 864×1536，普通1.25倍放大至1080 |
| D01＋U01 H3再接FlashVSR | 29＋43＝72 | 142＋215＝357 | 1152×2048普通缩小至1080，24fps；实际为两次RH任务 |
| 同段Wan＋InfiniteTalk＋FlashVSR | 146＋44＝190 | 730＋216＝946 | 1080×1920，25fps；复用已有成品 |
| 药3 H3＋FlashVSR / Wan融合基线 | 70 / 159 | 348 / 795 | 第二段素材有相似费用方向；媒体未列入首版 |

RH报告秒数不是纯GPU算子时间，也不是包含排队、上传、下载、人工审阅的全程时间。72与190的差距只对这些样本负责；质感、演唱气质、帧率和可用率尚未等价。

H3能呈现可辨认的唇形变化，但“支持音频参考”不是精准对嘴型通过证书。我们还做过静止脸负对照：即使完全没有嘴部动作，SyncNet也能给出随音频偏移移动的最佳位置，只是置信度很低。因此，偏移接近0不是充分证据。逐字听看、延长片段和换素材仍然必要。

## 脸和耳环可以同时给出不同答案

D01与U01是同源超分前后；D05是重新生成的另一条视频，不能当成纯粹的超分消融。

本例FlashVSR把耳环金属圈、麦克风网格描得更清楚，也加强了脸颊、鼻翼部分纹理与阴影边界。一些观看者会觉得脸更有加工感。不能由静态清晰度认定新增细节真实，或者全段没有闪烁。

T8也有H3首遍→潜空间放大→第二遍的路线。我们在剧情上测过4＋5步、1.5倍，不曾把这条路线用于本例唱歌。第二遍会改变嘴形和表情，不能当成只增加像素。区域修脸和完整VocalLock V3未在本例验证。

## 表情、互动与失败

| 镜头 | 本批实物 | 判断 |
|---|---|---|
| 浅笑 | E04 / E06两种子 | 有重复候选；第二种子短暂露齿，不能保证始终闭唇 |
| 大笑 | E05对E04，同图同种子 | 表情力度能区分；大笑目前一个样本 |
| 近侧手轻扶肩 | G05 / G06两种子 | 抬手、接触、停留有重复候选；接触点与手指仍需动态看 |
| 三人各自反应 | G01 / G03及其他配方 | 两人的主动作较符合；要求第三人只动眼睛时仍额外转头 |
| 复杂双采 | E02 | 假字幕负例；首遍已有杂纹，第二遍进一步描清；整次50币保留入账 |
| 多人长段唱歌、指定谁开口、复杂交叉动作 | 未测 | 不提供生产承诺 |

提示围绕“触发→接收→一个主反应→收束”组织，明确画面左右和人物特征。站位清楚、脸无遮挡的新图也在起作用；旧H3同图也有改善，不能把进步全归给配方。

## 时长与有效成本

本批唱歌原片226帧/24fps＝9.416667秒；两次FlashVSR都变成221帧＝9.208333秒，仍覆盖9.2秒歌曲。**这不是证明FlashVSR固定少5帧。** 展示整理片保留覆盖完整歌曲的帧数，没有补假嘴型。

19个任务全部交片，不等于19个内容全部合格。659币已计入失败内容、重复种子、旧H3对照和两次超分。两次前置绘图另记，费用未报告；研发人员与观看者的时间没有完整货币化。

有效成本应为：（生成＋超分＋重试与失败＋分摊准备费用＋人工）÷最终采用的可用秒数。目前缺少统一的人审采用秒数和人工价格，**有效成本数值留空**，不拿单条成功扣费冒充它。

全部19条的公开字段见 [tasks.json](../data/tasks.json)。删去了账号余额、任务访问标识、临时下载地址和本机路径；公开数据只含实验编号、设置、历史实扣、时间、输出数量与观察。
