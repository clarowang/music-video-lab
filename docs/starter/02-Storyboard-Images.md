# 分镜和生图：先想清画面为什么在这里

一个有效起点：**同一个人，在一首歌里呈现不同造型与处境。** 可以一直唱，也可以穿插只演不唱的镜头。别先规定必须10段；先听歌曲的情绪、句尾、间奏和高潮，再决定镜头数量。

## 1. 先出一页分镜

参考 `templates/storyboard.md`，每镜写清：哪段歌词/音乐、谁在画面里、唱还是只演、服装与场景、人物动作、相机动作、起止位置和风险。

先定镜头草案，再协调音频切点。长句可以占一个镜头，间奏可以单独安排动作；不会自动删除呼吸、停顿或空拍。短镜头如果不足2秒，可以生成一段更长源片再取用，但这属于另一个镜头编排版本，当前严格工具不替你默默扩长。

以单人MV为例：A近景原地唱 → B另一套有明显轮廓变化的衣服继续唱 → C沿廊道慢走只演 → D回到近景唱。不是所有镜头都需要走路，也不要一边转头、转身、绕镜头、递东西一边要求逐字口型。

## 2. 把参考分成三种职责

| 参考 | 主要约束 | 不要顺手复制 |
|---|---|---|
| 人物母版 | 脸型、五官、发型和识别特征 | 不强制每张穿同一套衣服、站同一处 |
| 服装参考 | 轮廓、材质、领口、肩线、配色 | 不用换一个小饰品冒充大换装 |
| 机位参考 | 视线高度、透视、脸的大小、肩臂关系 | 不把“去麦克风”误解成只擦掉麦克风而保留棚感 |

每张候选尽量回到稳定母版和明确参考独立生成。连续把上一张衍生图再拿来改，可能累积身份与质感漂移。若确实沿用某张派生图，记录原因并并排核脸。

## 3. 提示词拆成可改的几段

给你自己的 Codex 的生图任务示例：

```text
先看我给的人物母版、服装参考和机位参考。保持母版中的成年人物身份与真实脸部比例。
本镜服装：深墨绿缎面上衣，肩线与上一镜不同，近景能看出材质和领口结构变化。
场景：夜间酒店长廊，暖色壁灯，背景有纵深，环境细节适度。
构图：9:16较近的手机前置视角，眼睛接近镜头高度，脸和肩部为主体；手机与持机手不进入画面。
人物：准备开口唱歌，放松但克制，嘴部无遮挡，不露夸张笑容。
为后续轻微手持运动留少量边缘空间。不出现麦克风、录音棚设备、文字或水印。
只生成本镜的独立图片，不做九宫格，不把图片已完成当作视频已完成。
```

这是结构示例，服装、性格和背景由接收者的项目决定。调用实际可用的图像工具；若工具需要单独技能，按其当前要求读取参考图和使用。**包内没有通用生图API密钥或一键生图脚本**，因此你的 Codex 要先确认自己有哪些图像能力。不能把这个包当作“装上即获得同款生图模型”。

## 4. 先解决候选图的问题

通常先做少数代表方向，方向确认后扩成N张主图和适量备选（原使用方常用N+4，但不是每个人的规定）。整组并排看：脸是否一致、服装是否有大变化、相机距离是否相近、嘴是否清楚、手和饰品是否合理。

不同背景不能替代服装变化。曾经14张都换了环境，整体仍很同质；后来从旧服装资产取轮廓和材质差异，才更接近期望。也遇到某张人头偏小，1.2倍普通裁近就改善融入感；这只是那一张的处理，不是统一裁近倍数。

只裁切/普通缩放能解决大小，不能修正真实透视、身份或手指。新图应为足够大的9:16图；本包要求至少864×1536，先看真实细节，再决定裁切。小图硬放大满足像素数字，不等于高质量参考。

## 5. 把图片看成下一步动作的起点

- 原地唱：正面/轻侧面近景，嘴部不被发丝、手、麦遮挡；呼吸、眨眼和小动作足够。
- 手持自拍：透视、眼神、肩臂姿势先在图上合理；提示里的“handheld”并不保证真实手机跟拍感。
- 慢走：人物姿势与背景通道必须支持前进。图已坐死在沙发里，不能只改一个词就要求自然站起转身长走。
- 多人：在图和文字中说明左右/前后、衣服特征和角色分工。谁说话、谁听，需要实际视频看嘴；身份标签和音频参考都不等于逐角色嘴型保证。
- 不唱：提示自然闭嘴、看人或做事，并用静音驱动；最终再铺原曲。仅把提示改成“不唱”，同时喂强人声，可能仍张嘴。

输出主图与备选、对应实际提示、参考来源和选择理由。用户选定的图片绑定到镜头后，再去提交视频，避免跑错版本。
