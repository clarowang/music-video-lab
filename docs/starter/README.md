# 从分镜到成片：音乐视频制作入门版

**给人看的说明，也给 Codex 执行。** 从一首现成歌曲出发：设计分镜、准备人物参考、生图、用 H3 生视频，再对齐原曲、加字幕、剪成竖屏音乐视频。

阶段版本：2026-09-15。已并入音乐影像实验室的公开仓库；教程、H3 核心、逐镜准备和整首剪辑使用同一套代码。不含模型权重、账号或付费额度。

## 你只需要这样开始

1. **[下载仓库 ZIP](https://github.com/clarowang/music-video-lab/archive/refs/heads/main.zip)，解压全部文件** 到自己的一个文件夹，别在压缩软件里直接运行。
2. 在你自己的 Codex 中打开这个文件夹，把下面一段发给它。
3. 让它先解释并检查环境。正式做片时，再给它你的歌曲、人物参考和预算。

```text
请接管这个从分镜到成片：音乐视频制作入门版。先读根目录 AGENTS.md、README.md 和 docs/starter/01-Quickstart.md，再按当前阶段读相关说明。
第一轮先帮我理解整条流程，检查本机工具，并列出我已提供和缺少的材料。不要启动收费生成，也不要自动安装软件。
你可以自主阅读文件、检查参数和已有结果。需要我决定时，用人话一次问一个具体问题；已明确授权的工作连续做完。
先告诉我：你现在能做什么、还差哪个接入条件、怎样用离线演示验证。以后在 work 下保存我的项目、状态和日志，我换新聊天也能接着做。
```

不必先理解 Python、ComfyUI 或 API。让 Codex 解释这里的文件、改本歌配置、查报错。**它仍需要自己的工具权限、可用模型服务和你的选择；读懂资料不等于账号已接通，也不等于审美自动通过。**

## 整条流程，一句话一站

| 环节 | 在做什么 | 留下什么 |
|---|---|---|
| 歌曲准备 | 留住完整原曲，另备同一时间轴的人声和歌词字幕 | 原曲、人声 WAV、SRT、歌词文本 |
| 分镜 | 决定每段是唱、走、看、互动；再找合适的音乐切点 | 分镜表、人物参考、精确切点 |
| 生图 | 让参考中的人物穿对衣服、站到对的位置，准备后续动作 | 主图、备选、实际提示、选图记录 |
| 生视频 | 图片管人物与构图，音频管发音节奏，提示管动作和机位 | H3 原生片、实际工作流、taskId、费用 |
| 整理回片 | 检查是否足够长，普通放大到 1080，裁去多余尾巴，接原曲 | 按编号排列的 1080×1920 / 30fps 片段 |
| 剪辑 | 按共同时间轴组装，铺连续原曲，做字幕、标题和少量转场 | 成片、可改字幕、复跑参数、检查与待人审问题 |

**当前主路线：H3 864×1536 / 24fps / 8步 / FFN4 → 普通放大 1080×1920 / 30fps。** 默认没有 FlashVSR、AI 补帧和美颜。普通放大不会创造原本不存在的细节。

## 包里真正有什么

根目录 `tools/` 是共用 H3 核心及便携准备、收片、剪辑和可选 RH 单任务工具；`workflows/` 是 API 执行图，`recipes/` 是配方。`templates/` 放项目、分镜、接续日志和付费许可模板。不存在第二套 engine 副本。

`examples/offline/` 是合成几何图＋测试音的演示资料；先看 [离线演示视频](../../examples/offline/final.mp4) 或 [演示说明](../../examples/offline/README.md)。它演示文件如何衔接，**不是 H3 生成效果、真人唱歌或口型准确性的样片**。真实 H3 正负样片及历史费用见[公开项目](https://github.com/clarowang/music-video-lab)。

这套工具从已有歌曲开始。你可以使用自己的 IP、音乐、参考图及字幕字体；代码许可和素材许可分别看[许可范围](../../LICENSES.md)。输出为 MP4、ASS 和可读的参数记录。

新增可选环节：[原曲＋原词对齐字幕](../lyrics-alignment.md)，输出逐句与字/词级 SRT。它不制作歌词，也不保证每个字的时间准确。
